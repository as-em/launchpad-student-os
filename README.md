# Simple Taskboard

A lightweight student workspace built for Bangladeshi CSE students to manage daily labs, competitive programming (CP) practice, internships/clubs, alumni/faculty follow-ups, and CV project bullets.

## Features
- **Tasks & Time Tracking**: Add tasks with tags (`CSE-305`, `CP`), estimated minutes, and energy level (**Deep Focus** vs **Quick Task**), filter by status (`All`, `Pending`, `Done`), and edit time inline.
- **Internships & Clubs Board**: Track opportunities across `Wishlist`, `Applied`, `Interview`, and `Offer`.
- **Network Follow-Ups**: Keep track of alumni, seniors, and faculty mentors and mark check-ins as pinged.
- **CV Bullets**: Save project and contest achievements and copy bullet points in one click.
- **Browser Storage**: Automatically saves your data in `localStorage`.
